# Bus Ticket Frontend
[Documentación de Proyecto](https://github.com/alejosilvalau/bus-ticket-backend/tree/main/docs)

## Ejecutar el Proyecto Localmente
1. Clonar el repositorio
`git clone https://github.com/alejosilvalau/bus-ticket-frontend.git`

2. Instalar dependencias
`npm install` o `pnpm install`

3. Configurar variables de entorno
Crear un archivo `.env` en la raíz del proyecto y agregar las siguientes variables de entorno:
```env
VITE_IS_DEV=true
VITE_API_BASE_URL=/api/v1
VITE_API_DEV_TARGET=http://localhost:8080
VITE_API_PROD_URL=URL_DE_PRODUCCIÓN_DEL_BACKEND
```

4. Iniciar el proyecto
`npm run dev` o `pnpm run dev`
